# CLAUDE.md — контекст проєкту для Claude Code

## Що це

**Сюзерен: Безкоштовний Редактор Фентезі Мап** (англ. **Suzerain: Free Fantasy Map Editor**). Спершу робився для D&D-кампанії Олексія «Уже не ви» у світі **Сюзеренату**; тепер це публічний інструмент для всіх.
Редактор фентезі-мап для D&D-кампанії Олексія у світі **Сюзеренату** (грімдарк, перехід від ренесансу до промислової революції).
Мапи виглядають як чорнило на пожовклому пергаменті. Перша мапа — північ провінції **Крайтрен** (раніше Kraitsky): болотиста місцевість, розбите узбережжя, Штормгігантські гори.

- Інтерфейс **українською та англійською**. Код і розмітка пишуться українською, англійська накладається поверх (див. «Мови» нижче).
- Хостинг: **GitHub Pages**, статичні файли без збірки. Можливо, пізніше десктоп через Tauri.
- Користувач — розробник ігор (Unity/C#), технічні пояснення сприймає нормально.
- **Git:** зміни комітити й пушити одразу в `main` (без окремих гілок і PR) — так хоче користувач; сайт публікується з `main`.

## Архітектура

- Без фреймворків і бандлера. `index.html` підключає **класичні скрипти** (не ES-модулі) у суворому порядку:
  `i18n.js → i18n-en.js → default-map.js → core.js → render.js → nature.js → generators.js → templates.js → library.js → brush.js → ai.js → ui.js`.
  Усі верхньорівневі `const`/`let`/`function` спільні на глобальному рівні.
  Код, що виконується при завантаженні, стоїть тільки в `ui.js` (секція `boot`).
  Якщо переходити на модулі, роби це свідомо і для всього проєкту одразу.
- Світові координати мапи: `W×H` беруться з `data.W/H` і різні для різних мап. `W, H, FW, FH` — `let`; після будь-якої заміни `data` їх оновлює `applyMapSize()` (викликається з `ensureIds()`), вона ж скидає кеш текстури паперу.
- Рендер: `renderMap(scale, withDecor, noFrame)` малює всю мапу в offscreen canvas.
  Прев'ю тримає готове зображення `mapImg` і перемальовує його з затримкою (`scheduleRender`).
  `draw()` показує `mapImg` із трансформацією вигляду, а поверх малює контури, штампи й тексти. Штампи й тексти малюються живими і в `mapImg` не потрапляють, хіба що при експорті з `withDecor`.
- Інструменти: Вибір, Полігон, Овал, Крива (`tool = 'curve'`, вид `newCurve`: river|road|rail|path), Штамп, Текст. Опції активного інструмента (вид зони, вид кривої, штамп) — ліва панель `#opts`; кожен список має `data-for` з інструментами, для яких він показується.
- Панелі: права (`#side`) — завжди параметри мапи й «Контури й вибір»; ліва (`#opts`) — опції інструмента (`#toolOpts`) і налаштування вибраної фігури/штампа/тексту (`#objPanel`). `renderSide()` малює обидві через `renderPanel(el)`; `updateLeftPanel()` ховає/показує ліву. Зсув сцени при появі лівої панелі компенсується в `ResizeObserver`, щоб мапа не стрибала.
- Повзунки — тільки через `slider()` + `bindSliders(root, obj, after)`: поруч із кожним є поле для числа (приймає кому), значення обмежується min/max повзунка.
- **Клімат і ландшафт** (`nature.js`): `TREE_TYPES` (ліс: `trees`, окремі дерева: `settings.scatterTrees`) і `TERRAINS` (фігури `kind:'terrain'` з `terrain: snow|tundra|steppe|meadow|hills|marsh|desert`). Розміщення: гори → пагорби → болота → ліси → окремі дерева → поверхня (сніг, тундра, степ, поля, пустеля). Окремі дерева не ростуть у пустелі.
- Міграція v1→v2 (`migrateNature` з `ensureIds`): `kind:'marsh'` → ландшафт «Болото»; глобальний `settings.snow` → фігура «Сніг» на всю мапу з тією ж щільністю. Нові шаблони — одразу `v: 2`, без снігу.
- **Пензель** (`brush.js`): мазок + сусідні мазки того ж типу (`brush:true`) растеризуються, `traceMask` трасує контур → звичайні полігони. Гумка обрізає будь-які фігури вибраного типу; якщо мазок не дістав до краю — контур лишається як був. Дірка в суші стає озером, в інших типах — невидимий розріз (`bridgeHoles`). Кути суші за межами мапи закріплюються (`pinOffMap`).
- **ШІ** (`ai.js`, формат у `AI.md`): без ключів і сервера. Запит = інструкція (`aiSpec()` будується з `TERRAINS`/`TREE_TYPES`/`STAMPS`, тож завжди актуальна) + контекст + мапа (уся або зведення). Відповідь — блок `map-patch` з операціями `transform | set | add | delete | map` за `id` (або ціла мапа). `aiApply` працює на копії, `aiDiff` → підсвічування; перегляд «до / після» блокує редагування (`aiPreview`), `saveCurrent` під час перегляду нічого не пише. «Зберегти» = один крок «Назад». Якщо змінюєш формат даних — онови `aiSpec()` і `AI.md`.
- **Мови** (`i18n.js`, `i18n-en.js`): `MutationObserver` перекладає весь текст і атрибути `title/placeholder/aria-label` за словником `EN` (точний український текст → англійський; `EN_PATTERNS` для рядків з «…», частини через ` · ` і `: ` перекладаються окремо). Рядки зі змінними в коді — `L('укр', 'eng')`. Користувацький вміст (назви мап, підписи) — під `data-noi18n`. Довідка — дві версії (`data-lang`). Мова в `localStorage` `suzerain-lang`; перемикач — `#langBtn`, подія `langchange` перебудовує панелі. **Новий напис в інтерфейсі = рядок у `i18n-en.js`**; запит для ШІ (`aiSpec`, `aiBuildPrompt`) і `AI.md`/`AI.en.md` — дві окремі версії.
- **Стартовий екран** (`openStart` у `library.js`): мова (першого разу), «Продовжити» останню мапу, нова мапа з шаблону (шаблон з `example: true` позначено «Приклад від автора»). Поки бібліотека порожня, за екраном показано Крайтрен, але нічого не зберігається, доки користувач не створить мапу.
- **Підписи** (`labels.js`): поля `label, labelPos, labelSize, labelFont, labelItalic, labelSpread, labelAt` у штампів, зон і кривих. Зони й штампи — `below|above|left|right`, зони ще `inside` (`zoneLabelLayout`: найглибша точка + найдовша хорда біля головної осі, текст розходиться й повертається); криві — текст по літерах уздовж лінії, `above|below`, `labelAt` 0–1. Малюються живими в `drawDecor` (`drawShapeLabels`), потрапляють в експорт.
- Вибір мишкою: спершу лінії (річки, шляхи), далі найменша площинна фігура під курсором.
- Сітка зайнятості `occ` (1/4 роздільності, `FS = 4`) у `placeGlyphs` не дає горам, деревам і сніговим позначкам налазити на річки, шляхи, штампи й поселення.
- Поле відстані до води `buildField()` (chamfer) використовується для «на суші з відступом».

### Модель даних (`data`)

```js
{
  v: 1, W: 3200, H: 1513, seed: 7, rev: 3,
  settings: { scatter, snow },
  shapes: [  // порядок має значення для перекриття
    { id:'s7', kind:'land'|'lake'|'mountain'|'forest'|'marsh'|'vill'|'town'|'fort'|'stain'|'region',
      shape:'poly'|'ellipse', pts:[[x,y],...] | cx,cy,rx,ry,rot, ...параметри типу },
    { id, kind:'river'|'road'|'rail'|'path', shape:'line', pts, width, taper?, clear? },
  ],
  stamps: [ { id:'d12', type:'compass'|'house'|'manor'|'tower'|..., x, y, size, rot, label, labelSize, halo, clear } ],
  texts:  [ { id, x, y, w, h, text, size, font, align, bg, italic, bold, spacing, lineH } ],
  palette: [ { name, c:'#rrggbb' } ],   // власні кольори плям
  exportRect: { x, y, w, h }
}
```

- Згенеровані фігури позначені `gen: 'r:<regionId>:stream|pond|marsh'`. Старий формат `gen: 'wet'` теж трапляється.
- Ідентифікатори фігур мають вигляд `s<number>`, штампів і текстів — `d<number>`. Лічильник `uid` спільний (`ensureIds`/`ensureDecor`).

## Стиль малювання

- Кольори: чорнило `INK = #2a1b0e`, папір `PAPER = #e2cb94`, світлий папір `PAPER_L = #efe2bd`.
- Тіні — штрихування на правому/тіньовому боці (`K.hatch`), а не заливки. Вид у три чверті (`house`, `house2`, `block`, `tower`, `roofPyr`).
- Штампи малюються в коробці 100×100 одиниць навколо (0,0) через `stampKit(g, u)` і словник `STAMP_ART`. Новий штамп додається записом у `STAMPS` (назва й типовий розмір) і функцією в `STAMP_ART`.
- Рамка мапи, віньєтка й зернистість паперу додаються в `renderMap`.
- Не копіювати сторонні платні набори ассетів (наприклад, BeePixelCraft). Брати з них тільки манеру, а малювати своє.

## Важливі нюанси

- **Бібліотека мап** (`library.js`) у `localStorage`: `suzerain-maps-v1:index` (список `{id,name,W,H,created,updated}`), `…:map:<id>` (JSON мапи), `…:thumb:<id>` (JPEG-мініатюра), `…:current`, `…:templates` (шаблони користувача). `changed()` → `scheduleSave()` → `saveCurrent()`. Назва мапи — `data.name`; `restore()` (undo) її не чіпає. Старе автозбереження `LS_KEY` при першому запуску імпортується як перша мапа.
  Якщо змінюєш `DEFAULT_MAP`, додай відбиток старої (`mapFingerprint`) в `OLD_STARTERS` і зміни ключ `MIGR_STARTER` — тоді незмінені старі стартові мапи в браузерах оновляться один раз, а відредаговані залишаться.
- Файли: `saveFile()` — копія в `.json` (File System Access API у Chromium, інакше завантаження); `openFile()` відкриває файл як нову мапу в бібліотеці.
- Межі мапи: `shiftData(d, dx, dy)` зсуває всі координати (фігури, штампи, тексти, `exportRect`). Діалог «Межі» не модальний (`.modal.dock`), прев’ю малює `drawBoundsPreview()` у `draw()`.
- Шаблони нової мапи — `js/templates.js`: або `make(W,H)`, або готова `data` (при іншому розмірі розширюється/обрізається від центру).
- `dl.save({filename, data})` — обгортка для збереження PNG. Колись це була можливість (capability) Claude-артефакту, тому інтерфейс такий самий.
- Мури міст і фортець мають режими `wallMode: land|always|never`. Режим «land» маскується через `landL` у `drawWalls`.
- Генератор струмків: висоти → priority-flood → накопичення стоку. Тяжіння до широких річок — параметр `pull`.
- **Кеш GitHub Pages** (~10 хв): у `index.html` усі CSS/JS підключені з `?v=N`. При кожній публікації змін у CSS/JS збільшуй `N`, інакше браузер візьме старий скрипт до нової розмітки.
- Права панель без вибору: параметри мапи (`renderMapSettings`) і «Контури й вибір».
- **Довідка** «?» / F1 (`#helpModal`): вкладки «Основи / Інструменти / Гарячі клавіші» (`setHelpTab`), тексти — дві мовні версії (`data-lang`). Відкривається сама після першої створеної мапи (`suzerain-help-seen`). Галерея лісів і ландшафтів малюється тими ж функціями, що й мапа (`drawHelpSample`). Знімки — `img/help/<назва>.<uk|en>.jpg`, знімаються headless-Chrome у режимі `?shot=…` (`setupShot`, інструкція в `tools/help-shots.md`); після помітних змін інтерфейсу їх варто перезняти.
- Верхня панель: один рядок, якщо вміщається, інакше переноситься (`fitBar` додає `.wrap`); українські написи довші.
- Великі зміни перевіряй у браузері: рендер всієї мапи займає приблизно 1–2 с.

## Ідеї на майбутнє (обговорені з користувачем або логічні наступні кроки)

- Свої PNG-штампи (якщо користувач купить набір ассетів) з тими самими перетягуванням, розміром і підписом.
- Мости й броди там, де шляхи перетинають воду.
- Шрифти локально в `fonts/`, щоб працювало офлайн, плюс PWA (manifest + service worker).
- Шари. Свої PNG-дерева/позначки. Більше шаблонів (користувач накидає свої варіанти). Перетягування меж мапи мишкою прямо на сцені.
- Десктоп-збірка через Tauri: обгорнути цю ж статичну теку.
- Розбити `ui.js` на менші частини (панель, інструменти, файли).
