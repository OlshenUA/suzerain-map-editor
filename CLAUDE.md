# CLAUDE.md — контекст проєкту для Claude Code

## Що це

Редактор фентезі-мап для D&D-кампанії Олексія у світі **Сюзеренату** (грімдарк, перехід від ренесансу до промислової революції).
Мапи виглядають як чорнило на пожовклому пергаменті. Перша мапа — північ провінції **Крайтрен** (раніше Kraitsky): болотиста місцевість, розбите узбережжя, Штормгігантські гори.

- Інтерфейс і всі тексти **українською**.
- Хостинг: **GitHub Pages**, статичні файли без збірки. Можливо, пізніше десктоп через Tauri.
- Користувач — розробник ігор (Unity/C#), технічні пояснення сприймає нормально.

## Архітектура

- Без фреймворків і бандлера. `index.html` підключає **класичні скрипти** (не ES-модулі) у суворому порядку:
  `default-map.js → core.js → render.js → generators.js → ui.js`.
  Усі верхньорівневі `const`/`let`/`function` спільні на глобальному рівні.
  Код, що виконується при завантаженні, стоїть тільки в `ui.js` (секція `boot`).
  Якщо переходити на модулі, роби це свідомо і для всього проєкту одразу.
- Світові координати мапи: `W×H = 3200×1513` (беруться з даних).
- Рендер: `renderMap(scale, withDecor, noFrame)` малює всю мапу в offscreen canvas.
  Прев'ю тримає готове зображення `mapImg` і перемальовує його з затримкою (`scheduleRender`).
  `draw()` показує `mapImg` із трансформацією вигляду, а поверх малює контури, штампи й тексти. Штампи й тексти малюються живими і в `mapImg` не потрапляють, хіба що при експорті з `withDecor`.
- Сітка зайнятості `occ` (1/4 роздільності, `FS = 4`) у `placeGlyphs` не дає горам, деревам і сніговим позначкам налазити на річки, шляхи, штампи й поселення.
- Поле відстані до води `buildField()` (chamfer) використовується для «на суші з відступом».

### Модель даних (`data`)

```js
{
  v: 1, W: 3200, H: 1513, seed: 7, rev: 3,
  settings: { scatter, snow },
  shapes: [  // порядок має значення для перекриття
    { id:'s7', kind:'land'|'lake'|'mountain'|'forest'|'marsh'|'vill'|'town'|'fort'|'stain'|'region',
      shape:'poly'|'ellipse', pts:[[x,y],...] | cx,cy,rx,ry,rot, ...параметри типу },
    { id, kind:'river'|'road'|'rail'|'path', shape:'line', pts, width, taper?, clear? },
  ],
  stamps: [ { id:'d12', type:'compass'|'house'|'manor'|'tower'|..., x, y, size, rot, label, labelSize, halo, clear } ],
  texts:  [ { id, x, y, w, h, text, size, font, align, bg, italic, bold, spacing, lineH } ],
  palette: [ { name, c:'#rrggbb' } ],   // власні кольори плям
  exportRect: { x, y, w, h }
}
```

- Згенеровані фігури позначені `gen: 'r:<regionId>:stream|pond|marsh'`. Старий формат `gen: 'wet'` теж трапляється.
- Ідентифікатори фігур мають вигляд `s<number>`, штампів і текстів — `d<number>`. Лічильник `uid` спільний (`ensureIds`/`ensureDecor`).

## Стиль малювання

- Кольори: чорнило `INK = #2a1b0e`, папір `PAPER = #e2cb94`, світлий папір `PAPER_L = #efe2bd`.
- Тіні — штрихування на правому/тіньовому боці (`K.hatch`), а не заливки. Вид у три чверті (`house`, `house2`, `block`, `tower`, `roofPyr`).
- Штампи малюються в коробці 100×100 одиниць навколо (0,0) через `stampKit(g, u)` і словник `STAMP_ART`. Новий штамп додається записом у `STAMPS` (назва й типовий розмір) і функцією в `STAMP_ART`.
- Рамка мапи, віньєтка й зернистість паперу додаються в `renderMap`.
- Не копіювати сторонні платні набори ассетів (наприклад, BeePixelCraft). Брати з них тільки манеру, а малювати своє.

## Важливі нюанси

- Збереження: `saveFile()` / `openFile()` (File System Access API у Chromium, у Firefox/Safari через завантаження) плюс автозбереження в `localStorage` (`LS_KEY`).
- `dl.save({filename, data})` — обгортка для збереження PNG. Колись це була можливість (capability) Claude-артефакту, тому інтерфейс такий самий.
- Мури міст і фортець мають режими `wallMode: land|always|never`. Режим «land» маскується через `landL` у `drawWalls`.
- Генератор струмків: висоти → priority-flood → накопичення стоку. Тяжіння до широких річок — параметр `pull`.
- Великі зміни перевіряй у браузері: рендер всієї мапи займає приблизно 1–2 с.

## Ідеї на майбутнє (обговорені з користувачем або логічні наступні кроки)

- Свої PNG-штампи (якщо користувач купить набір ассетів) з тими самими перетягуванням, розміром і підписом.
- Мости й броди там, де шляхи перетинають воду.
- Шрифти локально в `fonts/`, щоб працювало офлайн, плюс PWA (manifest + service worker).
- Кілька мап і шарів, вибір розміру нової мапи, створення мапи з нуля (зараз «Нова» бере стартову).
- Десктоп-збірка через Tauri: обгорнути цю ж статичну теку.
- Розбити `ui.js` на менші частини (панель, інструменти, файли).
