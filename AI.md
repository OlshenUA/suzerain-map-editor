# Редагування мап за допомогою ШІ — Сюзерен: Безкоштовний Редактор Фентезі Мап

English version: [AI.en.md](AI.en.md)

Редактор не викликає ШІ сам. Користувач натискає **ШІ**, пише запит і копіює його разом з усією інформацією.
Далі він передає текст будь-якому ШІ: Claude, ChatGPT, Gemini, локальній моделі або агентові.
Відповідь ШІ користувач вставляє назад. Редактор показує зміни «до / після» з підсвіченими місцями, і користувач їх **зберігає** або **скидає**.

Цей файл описує, що ШІ отримує і що має повернути. Агенти можуть читати його звідси або з репозиторію.

## Що отримує ШІ

- Запит користувача.
- Розмір мапи `W × H` у пікселях. Координати: `x` праворуч, `y` вниз, `(0, 0)` — лівий верхній кут.
- Яка частина мапи зараз на екрані і що вибрано (id).
- Мапу: або повністю (JSON), або зведення (id, тип, межі кожної фігури) плюс вибрані фігури повністю.

## Формат мапи (скорочено)

```js
{
  W, H, seed, name,
  settings: { scatter, scatterTrees },
  shapes: [ { id: 's7', kind, shape: 'poly' | 'ellipse' | 'line', pts: [[x, y], ...] | cx, cy, rx, ry, rot, ...параметри } ],
  stamps: [ { id: 'd12', type, x, y, size, rot, label, labelSize } ],
  texts:  [ { id: 'd30', x, y, w, h, text, size, font, align, bg, italic, bold } ]
}
```

| kind | що це | параметри |
|---|---|---|
| `land` | суша (берег згладжується; кути за межами мапи закріплюйте двома точками за ~100 px від кута) | — |
| `lake` | озеро | — |
| `mountain` | гори | `min` 12–80, `max` 20–160, `density` 0.2–2 |
| `forest` | ліс | `trees`: conifer, broadleaf, mixed, palm, jungle, dead; `tree` 6–24 (розмір), `density` 0.1–2 |
| `terrain` | ландшафт | `terrain`: snow, tundra, steppe, meadow, hills, marsh, desert; `density` 0.1–3; для hills `size` 12–70 |
| `vill` / `town` / `fort` | село / місто / фортеця | `density`, `scale` 0.4–3; село `fields` 0–3; місто/фортеця `wall`, `wallMode`: land, always, never |
| `stain` | пляма чорнила/фарби | `color` `#rrggbb`, `opacity` 0.05–1, `blur` 0–40 |
| `region` | область генерації (не малюється) | `streams`, `ponds`, `marsh`, `pull` |
| `river` | річка (`shape: 'line'`) | `width` 1–30 (до 4.5 — одна лінія), `taper` |
| `road` / `rail` / `path` | дорога / залізниця / пунктирний шлях (`shape: 'line'`) | `width` 0.4–3 |

**Підписи.** Будь-яка фігура чи штамп може мати `label` (текст), `labelSize`, `labelFont`, `labelItalic`. Зони й штампи: `labelPos` = `below` | `above` | `left` | `right`; зони ще `inside` — текст розходиться вздовж зони (`labelSpread` 0–2). Криві (річки, дороги…): текст іде вздовж лінії, `labelPos` = `above` | `below`, `labelAt` 0–1 — де вздовж кривої, `labelSpread` 0–40 — розрядка в px.

Полігони замкнені самі собою, перша точка не повторюється. Порядок фігур важливий лише для перекриття.

## Що має повернути ШІ

Коротке пояснення і **рівно один** блок ` ```map-patch ` з масивом операцій. Не повертайте всю мапу: це довго й дорого, і легко щось загубити. Фігури, штампи й тексти адресуються за `id`.

```map-patch
[
  {"op": "transform", "id": "s7", "scale": 1.15},
  {"op": "transform", "id": "s29", "dx": 120, "dy": -40, "rotate": 10},
  {"op": "set", "id": "s29", "fields": {"trees": "broadleaf", "density": 1.4}},
  {"op": "add", "shape": {"kind": "terrain", "terrain": "snow", "shape": "poly", "pts": [[400, 80], [1200, 60], [1150, 380], [380, 420]], "density": 1}},
  {"op": "add", "stamp": {"type": "tower", "x": 1500, "y": 700, "size": 54, "label": "Вартова вежа"}},
  {"op": "delete", "id": "s1941"},
  {"op": "map", "fields": {"settings": {"scatter": 1.5}}}
]
```

| op | що робить |
|---|---|
| `transform` | `scale`, або окремо `scaleX` / `scaleY`, а також `dx`, `dy`, `rotate` (градуси) навколо центру фігури або точки `origin: [x, y]`. Найкращий спосіб зробити фігуру більшою, меншою, зсунути чи повернути. |
| `set` | замінити поля фігури, штампа чи тексту, у тому числі `pts`. Поле `id` змінювати не можна. |
| `add` | `shape`, `stamp` або `text`. `id` не потрібен: редактор призначить сам. Відсутні параметри отримають типові значення. |
| `delete` | видалити за `id`. |
| `map` | `name`, `seed`, `settings` (зливається з наявними). |

Редактор перевіряє кожну операцію. Помилкові пропускає й показує список проблем, решту дає переглянути «до / після».
Якщо ШІ все ж поверне цілу мапу (`{"shapes": [...]}`), редактор теж її прийме і підсвітить різницю.
